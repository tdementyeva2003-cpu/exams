# Экзамены: IELTS · GRE · DELF

Веб-приложение для подготовки к IELTS Academic, GRE и DELF B2: разбор заданий, шаблоны, обороты, практика с проверкой, орфографический диктант и словарь с карточками.

Открыть: https://tdementyeva2003-cpu.github.io/exams/

Устанавливается на телефон и ноутбук как приложение и работает без интернета.
