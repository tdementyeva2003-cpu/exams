# Экзамены: IELTS · GRE · DELF

Веб-приложение для подготовки к IELTS Academic, GRE и DELF B2: разбор заданий, шаблоны, обороты, практика с проверкой, орфографический диктант, словарь с карточками и подробный курс математики GRE на английском с переводом.

**Открыть:** https://tdementyeva2003-cpu.github.io/exams/

Устанавливается на телефон и ноутбук как приложение и работает без интернета.

---

## Как устроен репозиторий

| Путь | Что внутри | Трогать? |
|---|---|---|
| `content/` | всё содержание: тексты, шаблоны, лексика, задания, колоды | да, это и есть то, что редактируют |
| `content/ielts.js`, `gre.js`, `delf.js` | основа тренажёра: разделы, задания, практика, колоды словаря, ресурсы | да |
| `content/ielts-more.js`, `gre-more.js`, `delf-more.js` | дополнительные обороты, лайфхаки, орфография | да |
| `content/gre-math.js` | курс математики GRE: правила, примеры с решениями, термины | да |
| `index.html` | стартовая страница | можно, аккуратно |
| `ielts.html`, `gre.html`, `delf.html` | оболочки, которые подключают файлы из `content/` | обычно нет |
| `app/engine.js`, `app/engine.css` | движок и оформление | нет |
| `sw.js`, `manifest-*.webmanifest`, `icons/`, `fonts/` | работа офлайн, иконки, шрифты | нет |

## Как поменять текст

1. Открой нужный файл в папке `content` на github.com.
2. Нажми на карандаш **Edit this file**.
3. Найди нужное место поиском (Ctrl+F или Cmd+F) и исправь текст.
4. Нажми **Commit changes** → **Commit changes**.
5. Через 1–2 минуты изменения появятся на сайте. Приложение на телефоне подтянет их при следующем открытии с интернетом.

## Готовые образцы записей

Слово в колоду словаря (внутри `words: [ ... ]`):

```js
["mitigate", "смягчать, уменьшать вред", "mitigate the risks"],
```

Строка таблицы фраз (внутри `["phr", "Название", [ ... ]]`), формат тот же: фраза, перевод, пример (пример можно не писать):

```js
["I would argue that", "я бы утверждала, что"],
```

Лайфхак (внутри `["tips", "Название", [ ... ]]`):

```js
"Текст лайфхака.",
```

Абзац с переводом в курсе математики:

```js
["bi", "English text.", "Русский перевод."],
```

Формула с пояснением (внутри `["fx", [ ... ]]`):

```js
["a² − b² = (a − b)(a + b)", "разность квадратов"],
```

Пример с пошаговым решением:

```js
["ex", {n: "Example 9", tag: "Numeric Entry",
  q: "Question in English", qru: "Вопрос по-русски",
  steps: [["Step 1 in English", "Шаг 1 по-русски"], ["Step 2", "Шаг 2"]],
  a: "Answer · Ответ: 42"}],
```

Выделение жирным внутри текста: `**слово**`.

## Правила, чтобы ничего не сломать

- Текст всегда в двойных кавычках `"..."`. Если внутри текста нужны кавычки, используй «ёлочки» или пиши `\"`.
- Между элементами списка ставь запятую, после последнего элемента запятая не обязательна.
- Скобки `[ ]` и `{ }` должны закрываться в том же порядке, в каком открылись.
- Если после правки страница перестала открываться, открой файл → **History** → предыдущую версию и верни её, или попроси Claude починить.

Слова, добавленные внутри приложения через «Словарь → Добавить», хранятся на устройстве и в эти файлы не попадают. Чтобы сделать их частью сайта, сохрани прогресс в файл и попроси Claude перенести слова в колоду.
